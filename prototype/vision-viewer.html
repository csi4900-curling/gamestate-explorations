Curling / Original-resolution vision experiment

From pixels to board candidates.

Visible coloured-cap proposals, ice-plane calibration and explicit failure cases. Fourteen 1080p frames from Canada–Korea; two camera regions evaluated separately.

This is not a recovered game state. Dots on the board are coloured-cap pixels projected onto the ice plane. Handles sit above the ice, so these dots can be substantially displaced from the actual stone centres. Occlusions, false detections, active end and team identity remain unresolved. Simulator export is blocked.

Calibration check

Each camera uses four manually selected outer-ring/line intersections. Nine inner-ring/tee landmarks per view were withheld from fitting. These small residuals concern painted points on the ice, not above-ice stone handles. Nominal ring dimensions and same-annotator clicks limit the conclusion.

Observed failures

  • Two touching red caps merge into a rejected colour component.
  • A yellow delivery-stick head becomes a false stone proposal.
  • A red object on a player's equipment becomes another false proposal.
  • Reference paint suppression can hide a true cap overlapping a same-coloured painted feature.
  • Occluded stones and parked/in-play distinctions remain unresolved.
Method and reproducibility

Manual source-specific reference calibration → SIFT feature registration with spatial support and motion checks → red/yellow connected components → nominal stone-scale and shape filters → grey-body cue → reference paint suppression → visible-cap proposals. Registration rejection causes abstention. This is a transparent classical baseline, not a trained robust detector.

Geometric ROI: sheet-width band and target house/guard region to the hog line, expressed separately in each camera's local coordinates. Outside-ROI caps remain in provenance. Label matching uses same-colour one-to-one nearest pairs within 20 source pixels; ambiguous annotated regions are excluded explicitly.

Registration consistency is not external proof of correct camera identity. The experiment has no temporal stone tracking, no settled-shot identification and no validated simulator output. Calibration does not transfer to arbitrary uploads.
