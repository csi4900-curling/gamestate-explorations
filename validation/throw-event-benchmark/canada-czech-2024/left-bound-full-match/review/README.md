# Wider-bound full-match evidence explorer

Open [index.html](index.html) in a browser. It loads the local full-match 360p source and the generated [data.js](data.js) directly from disk. Filter the 147 raw candidate passages, including 12 development additions from the wider left-camera search bound, 79 original frozen flags (two now source-reviewed as false paths), 25 remaining screen abstentions and 31 outside-corridor candidates. Click a candidate to seek the broadcast and inspect its conditional path, partial board, preceding board comparison and camera-local observation tracklets. The [S41 browser capture](browser-s41.png) shows one of the recovered stone paths.

The page is generated by [build_left_bound_review_viewer.py](../../../../../prototype/scripts/build_left_bound_review_viewer.py) from the [integrated evidence timeline](../integrated-evidence-with-boards-development.json), [screen](../integrated-screen-development.json), [tracklets](../integrated-observation-tracklets-development.json), [adjacent-board ledger](../integrated-adjacent-boards-development.json), and preserved frozen screen. [provenance.json](provenance.json) stores all input and UI hashes. The original [79-candidate viewer](../../full-match-review/index.html) remains unchanged.

This is a **prediction-visible development review page**. It cannot be used for independent throw annotation; use the separate [blind review packet](../../blind-throw-review/index.html) for that purpose. Candidate times are observed passage estimates, and neither physical throw identity nor complete game state nor simulation readiness is established.
