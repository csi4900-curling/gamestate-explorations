# Full-match pre-split evidence explorer

Open [index.html](index.html) locally. The page loads the full broadcast and
all 147 raw candidate passages. Choose **Pre-split motion review** in the
filter to inspect six distinct withheld candidate windows with source-visible
moving-stone prefixes. S131 and S132 share the exact same observed prefix;
S132 is shown separately as a duplicate trigger, not a second motion event.
The [S40 browser capture](browser-s40.png) shows the partial path ending
before its ambiguous split. Each review row links the high-resolution source
sheet. The board is marked unobserved for these withheld candidates.

This is a **prediction-visible development viewer**, not an independent
annotation tool or a verified throw sequence. Its path coordinates are
conditional camera-local projections. No physical release, post-contact
stone identity, complete board, score, or simulation-ready replay is claimed.
The frozen 79-candidate and integrated 91-candidate event screens are
unchanged. The [proposal results](../../PRE-SPLIT-PROPOSAL-RESULTS.md) explain
the source and patch evidence; [provenance.json](provenance.json) hashes the
input artifacts and generated viewer files.

The page was generated by
`prototype/scripts/build_left_bound_review_viewer.py` with the 91-candidate
timeline, integrated and frozen screens, tracklets, adjacent-board ledger,
full-match stage-one marker audit, local 360p broadcast, and
`gap-review/pre-split-proposals-development.json` passed as
`--pre-split-proposals`. It uses the same file-compatible template as the
[91-candidate viewer](../review/index.html).
