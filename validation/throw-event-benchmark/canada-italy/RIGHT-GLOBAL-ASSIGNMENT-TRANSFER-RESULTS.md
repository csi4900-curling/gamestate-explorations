# Fixed global-assignment transfer on Canada–Italy 2024

The [predeclared plan](RIGHT-GLOBAL-ASSIGNMENT-TRANSFER-PLAN.md) froze the post-Estonia global frame assignment, 1650–2760 s interval and paired context rule before this Italy run. Italy has extensive earlier development exposure; this is an **unchanged-rule transfer**, not an independent event score.

The [global probe](right-global-area-fixed-transfer.json) preserves 33 raw tracklets and emits **19** right-view review paths. All 19 were rendered in four [source strips](right-global-area-source-review/manifest.json), and [same-agent source classes](right-global-area-source-review/source-prefix-classes.json) were saved before context scoring. Fifteen short paths show moving stones, two long stone-pixel paths have uncertain same-colour identity, and two paths follow people or wheelchair-associated pixels.

| Source-visible proposed prefix | Clear context | Cluttered review |
| --- | ---: | ---: |
| Short moving-stone path | 15 | 0 |
| Stone pixels, long-track identity uncertain | 2 | 0 |
| Person / wheelchair | 0 | 2 |

The [paired context result](right-global-area-combined-context-transfer.json) flags both people and keeps all 15 short stone paths in clear review. The stone-pixel proposals overlap **all 17** previously defined [same-agent coarse windows](blind-reference.json), one per window. I01 and I02 are the long identity-uncertain paths. In contrast with the earlier greedy two-second-gap diagnostic, I13 now has a short yellow-stone path (A026) rather than the long uncertain splice; the global assignment also retains the I04 and I16 short red paths. That is a useful within-family transfer of the association change, not certified physical-event recall.

Estonia still has an E15 colour-observation gap, and a single right-view tracker cannot be assumed to survive every camera change. Before these proposals drive game-state or coaching simulation, the pipeline needs cross-view event identity, independently reviewed complete-end throw labels, and validated post-shot board positions.
