# Fine-grid right-house alignment diagnostic

This is a development diagnostic after the per-run temporal-median house references were derived for Canada–Italy and Canada–Estonia 2024. Nine time-spread source frames per run showed substantial paint overlap in most samples but zero at the final sampled frame of each second run. The 90-second layout router is too coarse to localize those closing camera changes.

For each routed split-view run, sample the source every **5 s** at bin centres. At each sampled time, compute the unchanged HSV/morphology right-house paint mask from `prototype/split_house_reference.py`. Score the fraction of the run-reference paint mask also present at the same source pixels. Flag **overlap <0.25** as `house_paint_unresolved_review`; retain all other samples as `house_paint_aligned_sample`. Preserve every score, source SHA-256, reference hashes, and nearby provisional left-event IDs. Group consecutive unresolved samples for source review, but do not call unsampled frames negative, alter the provisional throw inventory, or infer throw F1. The threshold was selected after the nine-sample development probe; neither recording is independent validation.
