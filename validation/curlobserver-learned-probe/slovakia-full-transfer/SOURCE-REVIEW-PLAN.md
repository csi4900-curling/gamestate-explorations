# Source-only event review sampled before interval predictions

Three 300-second windows are selected from the Slovakia source SHA-256
`eba1d86944a2f4278b6e5e2c7549d12b47e5e8a51bf0c680b2db372c6ec12420`
without using the full-match candidate times. For each of the first
three consecutive eight-hex-digit words, interpret it as an integer,
take modulo 25, and multiply by 300 seconds. The resulting fixed
windows are **2100–2400**, **6900–7200** and **5100–5400** seconds.
They do not overlap the earlier 2400–2700 source-only shot study.

Make five-second full-frame contact sheets for each window. Review
only source frames and nearby video, recording every apparent live
delivery as a coarse time window and colour when visible; mark
uncertain or off-camera releases explicitly. Freeze that review JSON
before inspecting model candidate rows for these windows. Then compare
the already frozen full-match event ledger to the review without
changing thresholds. These are agent-authored development labels,
**not** independent exhaustive validation or exact release times.
