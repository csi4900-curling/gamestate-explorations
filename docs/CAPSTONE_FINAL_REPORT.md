# Curling broadcast video to game state: evidence and open gates

**Status:** Research prototype; final capstone results are not yet validated.

**Updated:** 16 October 2026.

**Scope:** This document replaces the October 2026 draft that claimed all 18 playbook steps were complete.

## What exists

The repository contains source-specific experiments for finding candidate deliveries in broadcast video, tracking visible stone-like objects, projecting selected observations into camera-local sheet coordinates, and extracting partial post-shot boards. It also contains official shot-order and board-diagram references, review viewers, and a separate CurlR win-probability experiment using official data. The source videos, labels, predictions, and code are linked by hashes in many validation artifacts. See the [project README](../README.md), [code audit](../validation/AUDIT.md), and [full reproduction audit](../validation/full-reproduction/README.md).

These are useful research outputs. None of the current video handoffs is certified as a complete, physically accurate game state or a simulation input.

## Results withdrawn from the previous draft

- The five-row Tier A/B position-error table (including the 1.84 cm headline) has no traceable evaluation in this repository. It must not be cited as a measured result.
- The purported 50-match commentary audit uses programmatically constructed states and a regex-based checker that recognizes only some claim forms. The 330/330 count is **recognized claims on synthetic inputs**, not an exhaustive factuality result on real matches or an LLM evaluation. [Generator](../prototype/scripts/run_commentary_and_audit_benchmark.py), [auditor](../prototype/reasoning/commentary_audit.py).
- The 4.73/5 and 4.40/5 “coach ratings” were generated by `simulate_coach_ratings` in commit `a573292`; no coach supplied them. They are withdrawn as evaluation results. The current smoke-check script no longer generates ratings.
- The [Step 18 rink page](../prototype/demo/index.html) plays hand-authored scenarios and values. It is an interface mock-up, not a video-derived replay. Its revolution values and ranges are invented examples, not measurements or empirically calibrated confidence intervals.
- The former draft's end-to-end, fully validated, and all-steps-green claims are withdrawn. The [playbook](../curling-cv-playbook.html) is a plan and no longer pre-marks completion.

## Open validation gates

1. Freeze one integrated event pipeline and score complete, untouched recordings against independently prepared, exhaustive timestamped throw references, including quiet periods and coverage gaps. The [event benchmark](../validation/throw-event-benchmark/README.md) defines a provisional per-recording target of at least 0.95 precision and 0.95 recall.
2. Independently label post-shot boards on held-out source frames. Report coverage, missing stones, false stones, position discrepancy, camera tier, and collision/cluster conditions. Keep diagram-coordinate agreement distinct from measured physical-centimetre accuracy.
3. Validate cross-view physical identity, coordinate alignment, release and settle times before exporting complete trajectories or simulation-ready states. The [cross-view audit](../prototype/cross-view/README.md) records provisional links and a 0.61 m simultaneous-projection disagreement in one studied handoff.
4. Evaluate commentary on real, provenance-linked inputs. Obtain actual human ratings if coach usefulness is a claim. Treat template output and synthetic checks as software demonstrations until then.
5. Rewrite the capstone conclusions to match the frozen results, including failures and abstentions. The current project is a substantial research prototype, not a completed video-to-coaching system.
